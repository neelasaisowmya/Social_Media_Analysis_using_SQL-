# 📊 E-Commerce Sales Dashboard in Microsoft Excel

> An interactive Excel dashboard that analyzes e-commerce sales performance using Pivot Tables, Pivot Charts, KPIs, Slicers, and Excel formulas to generate actionable business insights.

---

## 🌟 Project Overview

This project focuses on analyzing an e-commerce sales dataset and transforming raw transactional data into an interactive business dashboard in Microsoft Excel.

The dashboard enables users to monitor sales performance, customer behavior, product profitability, and regional trends through dynamic visualizations and KPI cards.

**Project Type:** Data Analytics | Business Intelligence Dashboard

**Tool Used:** Microsoft Excel

---

## 🎯 Business Problem

Businesses generate thousands of sales records every month, making it difficult to identify trends and monitor performance.

This dashboard helps answer key business questions such as:

* Which product categories generate the highest revenue?
* Which regions contribute the most sales and profit?
* Who are the top customers by revenue?
* How do monthly sales and profits change over time?
* Which products perform best across different regions?
